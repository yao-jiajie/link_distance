# 验证加速：精确探针缓存与批量符号传播

## 范围

这是点云到函数优化的第四项。优化只改变验证的执行方式，不减少证书或数值审计
覆盖：体、面、边、顶点、无界区间、原始点、体素中心和角点、边界偏移点、随机点、
有限差分点及零面射线仍全部保留。重复探针仍逐次进入统计和导出。

## 实现

`ValidationValueCache` 使用三个 `double` 的完整位模式作为坐标键。因此相邻浮点数
不会合并，`+0.0` 和 `-0.0` 也保持不同。缓存持有对应的不可变 `CompiledTree` 快照，
只允许通过该程序实际求值来填充，避免注入其他几何或系数快照的值。

boundary-direct 的世界坐标验证先缓存硬值。距离审计随后复用这些硬值，并在审计内部
缓存同一坐标的硬值、平滑值、解析梯度、参考距离和占据状态。有限差分和零面射线若
命中已完成的主探针，也复用其平滑值。缓存容量有界为 200000 个坐标，与原探针数量
上限一致。

`--validation-cache auto|none|exact` 默认 `auto`。强制缓存对相机树有效，但在小树上
哈希成本高于省下的求值，因此自动模式只在 `SmoothTree::workPerQuery() >= 256` 时
启用；该判定只依赖程序结构，不依赖本次计时。C++ 审计 API 仍默认关闭缓存，保持
原调用者行为。

完整符号证书把最多 64 个 stratum 编入两个 `uint64_t` 掩码，分别表示负号和正号。
对 MIN，负号取并集、正号取交集；对 MAX，负号取交集、正号取并集；两个集合之外
即为零。遍历顺序、叶平面符号、期望占据分类、错误计数和 witness 顺序保持不变。
`--sign-propagation scalar|packed` 默认 `packed`，标量路径保留用于独立成对核对。

工作量上限仍按原逐 stratum、逐探针最坏成本扣减，缓存命中不会扩大请求所能覆盖的
验证规模。新增指标区分逻辑出现次数和实际求值次数：

| 指标 | 含义 |
| --- | --- |
| `sign_propagation_batches` | 标量为 strata 数，packed 为 `ceil(strata/64)` |
| `distance_probe_cache_hits` | 复用完整探针结果的出现次数 |
| `distance_probe_evaluations` | 实际计算完整探针结果的坐标数 |
| `distance_hard_cache_hits/evaluations` | 从前一验证阶段复用和实际硬查询次数 |
| `distance_diagnostic_cache_hits/evaluations` | 有限差分、射线中的平滑值复用和求值次数 |

## 成对实测

2026-09-09，本机 Release，`h=0.04 m`、1 mm LSE 误差预算、结构共享和二元内核开启；
每个模式 1 次预热、5 次测量，三模式轮换顺序。完整结果位于
[output/validation_acceleration_benchmark_final](../output/validation_acceleration_benchmark_final/report.md)。

相机数据结果：

| 模式 | 符号 strata / 批次 | 距离探针 / 实际完整求值 | 硬值实际求值 | 证书 ms | 距离审计 ms | 完整验证 ms |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 标量、无缓存 | 12673 / 12673 | 6705 / 6705 | 6705 | 16.163 | 239.670 | 262.544 |
| 标量、缓存 | 12673 / 12673 | 6705 / 4713 | 155 | 16.745 | 174.478 | 198.546 |
| packed、缓存 | 12673 / 199 | 6705 / 4713 | 155 | 2.821 | 176.325 | 185.830 |

缓存命中 1992 次完整探针、4558 次前阶段硬值及 64 次诊断平滑值。相对于标量无缓存，
缓存使距离审计中位数下降 27.2%；组合 packed 后完整验证下降 29.2%，构建加验证的
`total_ms` 从 263.597 ms 降到 186.923 ms，下降 29.1%。

强制缓存的九个场景中，小树出现约 3% 到 13% 的完整验证回退；这就是默认使用
结构工作阈值而非无条件启用的原因。packed 在相机证书上下降约 83%，小证书的绝对
时间只有约 0.04 到 0.18 ms，波动和固定成本占主导，不据此承诺普遍加速。

## 验证

- 单元测试逐项比较 packed 与 scalar 的全部计数、分类和 witness，覆盖 255 个体素
  模式、局部树、人工边/点零以及随机图形。
- 缓存测试覆盖精确重复、signed zero、相邻浮点数、容量上限、错误工作区、非有限
  坐标、程序生命周期和错误快照拒绝。
- 审计测试逐探针对比坐标、硬值、平滑值、梯度、参考距离及每条零面射线；缓存前后
  保守 `work_used` 相同。
- 成对 benchmark 每轮核对树、几何、探针 CSV、梯度、射线和除缓存/耗时指标外的
  完整验证 JSON。
- Release 全部 32 项 CTest 通过；相关 4 项核心 C++ 测试另以 ASan/UBSan Debug
  构建运行通过，设置 `ASAN_OPTIONS=detect_leaks=0:halt_on_error=1` 和
  `UBSAN_OPTIONS=halt_on_error=1`，本次不包含 leak detection。

该优化不改变函数、平滑公式、距离精度或证书含义。后续第五项已加入
[多帧几何和程序缓存](multi_frame_reuse_results.md)，并把跨帧保留的验证值绑定在同一
不可变程序快照上。
