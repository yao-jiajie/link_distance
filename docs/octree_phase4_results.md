# Phase 4 结果：构建更快，不等于实体包络更完整或树更小

已完成合成/模拟数据的 42 组参数配置、84 项后端对照。每项预热 1 次、正式测量 3 次，
串行轮换执行；另外测量现有 C++ 递归树求值器。没有改动几何、聚合或树后端算法。
最终验收失败项为 0，所有原始点均通过零阈值包含检查。

本轮没有真实扫描输入；`measured_clouds=0`。模拟相机数据不能称为实测机器人场景。
Phase 4 的测试框架与当前合成/模拟矩阵已完成，实测数据验收仍待补充。

## 实验设置

2026-09-08，本机 Release (`-O3 -DNDEBUG`)；CGAL 5.6.3。
5 个合成场景（cube、L、U、6 mm 薄壁、ellipsoid），每场景 256/1024 点，
噪声坐标半宽 0/0.003 m，voxel=0.02/0.04 m；再加模拟相机 1655 点的两种体素尺寸。
Alpha-tet 使用 alpha=3h、offset=h、exact plane reduction，本轮 offset retries 均为 0。
Octree 使用 rect，关闭可选 Phase 3 边界导出。所有二进制/输入哈希均留存在结果中。

每组使用相同的原始点、全部体素角点/中心、1024 个公共均匀查询，并对理想几何
各生成 512 个独立表面/内部探针；L/U 再测 512 个凹槽核心区域探针。
完整协议见 [octree_phase4_protocol.md](octree_phase4_protocol.md)。

## 主要结论

1. Octree 在本轮全部 42 组的核心构建中位数更低。逐组 Alpha/Octree 构建时间比为
   3.77–14.97，中位数 5.40。这里的中位数是“各组时间比”的中位数，不是混合所有
   样本后的总时间比；不是硬实时承诺。
2. Octree 只有 8/42 组的树更小，只有 13/42 组的查询中位数更低。
   构建更快不代表下游 CBF 评价更快，不能仅优化前端构建时间。
3. 两后端均包含全部原始点，但当前精确 Octree 表达的是观测体素并集，不能保证
   未观测实体内部被填满。它不是已经完成的障碍物实体重建。
4. Alpha 在实体内部探针上覆盖更多，但当前全局 alpha/offset 会明显侵入凹槽。
   更粗参数常减小树，也可能大幅扩大碰撞几何，不能简单称为精度提升。
5. 噪声影响并非单调。添加 3 mm 坐标半宽噪声后，本矩阵 Alpha 树节点比为
   0.820–1.259，Octree 为 0.945–1.208；体素索引/局部合并仍对跨网格边界的扰动敏感。

## 不能忽略的几何差异

以下是 1024 点、无噪声、h=0.04 m 的典型样例，比例来自有限探针，不是严格覆盖证明：

| 场景 / 指标 | Alpha-tet | Octree rect |
| --- | ---: | ---: |
| 立方体：实体内部探针覆盖率 | 100% | 36.9% |
| U 型：实体内部探针覆盖率 | 100% | 67.8% |
| U 型：指定凹槽区域被填充比例 | 100% | 0% |
| 6 mm 薄壁：实体内部探针覆盖率 | 100% | 100% |
| 6 mm 薄壁：输出体积 / 理想实体体积 | 41.79 | 15.88 |

薄壁虽然探针全部覆盖，两种输出都明显过厚：h=4 cm 相对于 6 mm 壁厚太粗。
体积比只描述体积，不独自证明集合包含。U 型的 100% 凹槽探针填充仅指预定义的核心
区域，不能由此宣称已经测量所有孔洞或验证了全局拓扑。

模拟相机理想椭球内部探针覆盖率：Octree 在 h=0.02 m 时约 14.3%，h=0.04 m 时
约 40.6%；Alpha 两档均为 100%。所有原始点仍均被包含，因此“raw 无漏包”与
“完整物体无漏包”确实是不同要求，不能互相替代。

## Alpha 体素探针的微小零阈值残差

公共探针发现 `u_n256_noise0_h0.04` 和 `u_n256_noise0.003_h0.04` 各有 16 个
体素角点/中心探针满足 F>0，总共 32 次（没有对共享角点去重）。正值范围约
3.02e-18–9.26e-18 m。所有公共均匀探针中的 V\C 计数为 0，原始点正值计数为 0。

这属于极小的数值边界残差量级，不是已证实的宏观几何缺口；但零阈值判定确实为 outside，
所以没有把这 32 次改写为 0，也没有宣称 Alpha 严格覆盖整个 occupied union。
导出的 quality/CSV 同时保留正值计数、最大正值和 1e-10 m 分桶，后者只是诊断，
不改变分类规则。Octree 的体素探针正值计数为 0，并保留其原有精确构造证书。

本轮“验收通过”指：后端自身验证通过、原始点零阈值包含、raw/simplified 一致、
各路线重复构建稳定，以及 Octree 的精确体素验证；不表示通过了未知实体全覆盖或
Alpha 全体素集合包含的严格证明。

## 后续边界

下一步若要表达完整实体，必须先确定怎样处理未观测内部及凹槽，再设计保守凸近似的
长度/体积预算。直接把现有内部面删除，或继续增大体素，都不能同时解决这些问题。
这涉及几何语义/误差预算的选择，本阶段没有擅自启用近似填充。

真实 XYZ 输入可接入现成脚本，但还没有真实扫描实验或机器人闭环部署验证。
